# AlienFlow

Personal Android dictation with a movable alien bubble, live text in the focused field, very light corrections, and a user-supplied OpenAI API key.

## Product contract

- Keep the selected keyboard.
- Default to live inline transcription and very light corrections.
- Use a 25% idle-opacity alien bubble with adjustable appearance and remembered position.
- Preserve existing text and manual edits; never automatically submit a field.
- Provide configurable lightweight history and connection recovery without an application word quota.

## Current status

Implementation has been authorized. The initial source, build workflow, and verification record are being prepared. No working APK or device compatibility is claimed by this initialization commit.

The implementation specification and reproducible build instructions will live in this repository alongside the code. API keys are entered on the phone and must never be committed.
