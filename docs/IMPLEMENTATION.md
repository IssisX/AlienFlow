## Implemented changes

Unknown-offset keyboard windows use cursor-relative ownership, independent of stale absolute callbacks and accessibility presentation. Validate local selection, every overlapping anchor and the complete replaced suffix. First insertion uses the current selection; revisions delete only observed owned text directly before the cursor, confirm that deletion, then commit once and confirm actual returned text/cursor. Known-offset edits retain their existing coordinate route. Cancellation and manual typing retain the ownership guards. Input lifecycle epochs reject operations from replaced connections; a same-editor restart preserves the binding while retiring old in-flight work.

While active, losing a field releases its writer while capture continues. A new field with a keyboard connection cannot bind until input is started in a newer lifecycle generation; early accessibility focus cannot attach the old connection to the new field.  Each focus boundary commits the preceding audio under the transport's capture lock. Startup frames retain their editor epoch across the handshake. Acknowledged audio items retain that epoch through deltas, finals and cleanup. After-stop cleanup edits only the current segment while retaining all other segments in history. The coordinator writes only the current field's segment. Speech captured with no eligible field and delayed old-field results remain in the complete history transcript. Returning to an app binds afresh and appends only its new segment. Termux receives only its current final segment once after Stop, without Enter. Switching while finishing preserves the pending result instead of adopting a new target. Cancellation can restore only the current field's still-owned span; earlier field segments stay untouched.

No microphone restart, keyboard replacement, app allowlist, timeout increase, automatic resending, AAB or provider/model change. Original signing identity, package, settings, artwork and stored user data are preserved.
